Add the IP address in /etc/hosts : ... 10.10.10.4 legacy.htb ... First run a nmap scan: Only 2 ports seem interesting: 139 and 445 which are SMB ports. We can run some enumeration on them: We got some data but nothing really useful. smbclient doesn’t return anything when we want to list shares. The only thing remaining is the OS version which seems to be Windows XP that is a very old version. It should have an exploit related to it: MS08-067 is a good candidate and is directly integrated to metasploit . Let’s try it: Observe the options to know what to set: Run the exploit: We are now Administrator of the machine! Here the other solution to hack the box (:p) without metasploit .
