Link to the OSINT challenge video: https://www.youtube.com/watch?v=c4q7XrAy5g4 I urge you to try by yourself before looking at this solution Solution We wont lost any time and directly perform a reverse image search on the painting seen in the video: We have several matches for this painting. The first ones are related to the artist who made it. But it doesn’t give us any clue about its location. So if we scroll down a bit and browse the results, we find these interesting links: It says Hi-Wire Brewing . So let’s search for this brewing: There are multiple shops in different states. If we go back to the previous reverse image search, in the results, we see something starting with Knoxv... . We’ll investigate this way. On the Hi-Wire Brewing website, we can list all the shops: https://hiwirebrewing.com/ Bingo, this matches our previous search!
