A very few pieces of information are given during the video, so we must focus on the correct ones. Link to the OSINT challenge video: https://www.youtube.com/watch?v=Hxp5uLV7AD8 I urge you to try by yourself before looking at this solution Solution As you may know, reverse image search has been very relevant so far. We used it a lot in the previous challenges and… it won’t change for this one 😀 Identifying elements from this video was the hardest part because we don’t have anything that could really be used as a clue for our searches, except that wall with names engraved on it. The wooden table is clueless, same for the two pictures on the wall. So this is our unique starting point for now. From all the thumbnails, this one seems to match the most. It is related to a bar and saloon named Genoa . https://travelnevada.com/bars/genoa-bar-saloon/ But from their website and images found on Google, no wall with names written on it is present: So it must not be the correct place. If we continue to scroll down the results of Google Lens, we are able to identify this part of the wall which is pretty identical: It says The Tav . So let’s take a look closer: https://www.yelp.com/biz/the-tav-ellensburg Both the wooden table and the wall looks the same. But we must be sure about our guess: We can find other photos that match the location: https://www.tripadvisor.com/Restaurant_Review-g58456-d804471-Reviews-The_Tav-Ellensburg_Washington.html#photos;aggregationId=101&albumid=101&filter=7&ff=295971651 And if we compare to the video: The text and symbols aren’t identical but they’re similar. Finally, find the location of this bar/restaurant: This place is not far from Seattle (as mentioned in two of the previous challenges). We can conclude this is the correct location!
